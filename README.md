# Потоковые алгоритмы

Учебная презентация по курсу «Теория алгоритмов» (3 курс).
**Автор:** Нехайчик Софья

🔗 **[Открыть презентацию в браузере](https://budd-son.github.io/StreamingAlgorithms-/)**

## 📌 О проекте
В работе рассмотрены базовые концепции обработки потоковых данных, ограничения потоковой модели и основные алгоритмы, позволяющие работать с большими объемами данных за один проход с сублинейной памятью.

## 📚 Рассматриваемые темы
* **Модели данных:** Cash Register, Turnstile, Sliding Window.
* **Поиск частых элементов:** Алгоритмы Бойера-Мура и Мисры-Гриса.
* **Вероятностные структуры (Скетчи):** Count-Min Sketch, HyperLogLog.
* **Выборка и фильтрация:** Reservoir Sampling, Bloom Filter.
* **Точные и приближенные структуры:** Поиск Top-K (min-куча), медиана потока (две кучи), P², t-digest.
* **Применение:** Брокеры сообщений (Kafka), машинное обучение, кибербезопасность.
